# 📄 Конструктор шаблонов студенческих документов

Веб-приложение для автоматического создания типовых студенческих документов — заявлений, справок, титульных листов и др. Позволяет упростить документооборот и сократить время на оформление.

## 📌 Описание

Сервис предоставляет готовые шаблоны, в которые пользователь вводит только переменные данные (ФИО, группа, дата и т.д.), после чего генерируется документ в формате `.docx`. Проект реализован с использованием современного стека:

* Backend: **FastAPI**, **Jinja2**, **docxtpl**, **SQLite**
* Frontend: **React**, **Material UI**
* Развёртывание: **Docker**, **docker-compose**

## 🚀 Возможности

* Выбор шаблона из нескольких категорий (заявления, титульные листы и др.)
* Автоматическая генерация документа на основе введённых данных
* Возможность предварительного просмотра
* Сохранение «кейсов» (наборов параметров) для повторного использования
* Простая установка через Docker

## 🛠️ Установка и запуск

### 🔧 Локально

```bash
# Клонируем репозиторий
git clone https://github.com/your-username/docbuilder.git
cd docbuilder

# Backend
cd backend
python -m venv venv
source venv/bin/activate  # или venv\Scripts\activate на Windows
pip install -r requirements.txt
uvicorn app.main:app --reload

# В другом терминале: frontend
cd ../frontend
npm install
npm start
```

### 🐳 С помощью Docker

```bash
docker-compose up --build
```

Приложение будет доступно по адресу: [http://localhost](http://localhost)
